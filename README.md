# 杭州二手房房价预测分析 (Hangzhou House Price Prediction)

### 项目简介
本项目基于 Python 对杭州市二手房数据进行全流程分析。项目涵盖了从**链家网数据爬取**、**数据清洗与特征工程**，到**可视化分析**及**机器学习房价预测模型**构建的完整数据科学工作流。

---

### 技术栈
* **数据采集**: Python `requests`, `lxml` (爬虫)
* **数据处理**: `pandas`, `numpy`
* **可视化**: `matplotlib`, `seaborn`
* **机器学习**: `scikit-learn` (线性回归, 随机森林等)
* **开发环境**: Jupyter Notebook

---

### 文件结构说明
* `爬虫代码.py`: 针对链家杭州二手房页面的爬虫脚本。
* `数据处理.py`: 对原始数据进行清洗、缺失值处理及特征提取。
* `数据可视化.ipynb`: 探索性数据分析 (EDA)，分析区域、户型、楼层对房价的影响。
* `模型预测.ipynb`: 构建机器学习模型预测房价，并评估模型性能。
* `data/`: 存放原始数据集及处理后的中间数据。

1. 安装依赖: `pip install pandas matplotlib seaborn scikit-learn`
